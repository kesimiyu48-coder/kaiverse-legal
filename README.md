# Kaiverse Studios Legal Pages

Static legal website for the Kaiverse Studios Discord AutoModeration bot.

## Publish with GitHub Pages

1. Create a **public** repository named `kaiverse-legal` under `kesimiyu48-coder`.
2. Upload `index.html`, `terms.html`, `privacy.html`, and `styles.css` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site.

Expected URLs:
- https://kesimiyu48-coder.github.io/kaiverse-legal/
- https://kesimiyu48-coder.github.io/kaiverse-legal/terms.html
- https://kesimiyu48-coder.github.io/kaiverse-legal/privacy.html

## Before submitting to Discord

Verify the deployed bot and its hosting configuration. This policy assumes the bot does not intentionally store deleted message content or violation records. Check application logs, hosting logs, monitoring, backups, and any connected services. Update the policy if actual practices differ.

These templates are informational and are not legal advice. Review them for your actual service and applicable law.
